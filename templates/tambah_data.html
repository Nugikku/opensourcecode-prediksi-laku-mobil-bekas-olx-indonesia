Opsi B: Tambah Data Tanpa CSV / Scraping Instan Web

Dibatasi Sistem

Mencoba menambahkan data tanpa file CSV hasil scraping atau meminta server melakukan scraping instan tanpa melewati prosedur scraping.py.

Mengapa penambahan data wajib menggunakan hasil scraping manual?

  • Membutuhkan id_iklan asli dari OLX agar deduplikasi akurat.
  • Penentuan ambang kuantil Q33 dan Q67 wajib berasal dari populasi iklan pasar riil.
  • Browser Chromium Playwright memerlukan pengawasan lokal saat menyadap API OLX.
